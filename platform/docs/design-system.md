# Design Direction

The website should feel like a serious control room, not a generic startup dashboard.

## UX Model

The target layout is:

- left navigation rail for workspace and governance surfaces
- central content area for projects, requests, runs, and work packages
- right drawer for policy, approvals, and run context

This is intentionally similar to Supabase in structure:

- durable sidebar
- information-dense cards
- inspector/drawer feeling on the right
- clear operational status surfaces

## Palette

- `ink`: primary control color, used for navigation and high-trust surfaces
- `slate`: structural neutral for text and borders
- `cloud`: light operational background for panels
- `parchment`: warm base tone to avoid sterile blue-gray dashboards
- `moss`: safe dispatch and approved governance paths
- `amber`: review and watch-state emphasis
- `ember`: escalation, caution, and refusal emphasis
- `blush`: soft escalation background

## Why This Palette Fits

The product is about:

- trust
- review
- bounded execution
- governance
- operational visibility

So the color direction should feel:

- sober
- inspectable
- warm enough for long sessions
- distinct from default dark-purple AI products
