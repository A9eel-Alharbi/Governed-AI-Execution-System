# v1.0.0-test-phase

This release publishes the first complete open-source reference implementation of the Governed AI Execution System.

## What It Includes

- a six-layer governed execution architecture
- the AOS/CDD repository-native framework artifacts and templates
- `agent_control_stack` for interpretation, policy, dispatch, and bounded execution
- human-in-the-loop approval gate
- dry-run mode with explicit write enforcement
- observable rollback and failure handling
- policy feedback loop with versioned history
- single-request project lock for v1
- reference platform UI and API
- audit, eval, ops reporting, retention, and CI policy gating

## Core Principle

The LLM is not the controller.
It is the bounded executor inside a governed system.

## Intended Use

This release is intended for:

- evaluation
- pilot use
- architecture study
- self-hosted experimentation
- extension by teams building governed AI software workflows

## Known Limitation

Platform policy edits are versioned and audited, but are not yet automatically written back into connected repo policy artifacts.
