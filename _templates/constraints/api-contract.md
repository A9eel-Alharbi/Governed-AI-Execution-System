# API Contract Companion Template

> This document exists to govern what the OpenAPI file means operationally. The OpenAPI 3.x file is the canonical source of truth. Prose-only API descriptions are forbidden.

## Document Control

- Document ID `[required]`: `api-core`
- Owner `[required]`: `[API owner]`
- Last validated `[required]`: `YYYY-MM-DD`
- Stability class `[required]`: `low` or `mixed`
- Canonical source `[required]`: `constraints/openapi.yaml`

## 1. API Surface Covered `[required]`

Example:
`Subscription lifecycle, tenant usage submission, and usage report retrieval endpoints.`

## 2. Endpoint Inventory `[required]`

| Method | Path | Auth Method | Versioning Rule | Stability | Notes |
|---|---|---|---|---|---|
| `POST` | `/v1/subscriptions` | `Bearer JWT` | `URI versioned` | `low` | `Create tenant subscription` |
| `GET` | `/v1/subscriptions/{id}` | `Bearer JWT` | `URI versioned` | `low` | `Fetch one subscription` |

## 3. Request and Response Rules `[required]`

Example:
- `All request and response schemas must be declared in OpenAPI components.`
- `All 4xx and 5xx responses must use ErrorResponse or an endpoint-specific documented schema.`
- `Undocumented fields are forbidden in production responses.`

## 4. Field Behavior Matrix `[required]`

| Field | Scope | Behavior | Notes |
|---|---|---|---|
| `id` | `all resource responses` | `read-only` | `Generated by service` |
| `tenantId` | `subscription create request` | `write-once` | `Cannot be reassigned after creation` |
| `cancelAt` | `subscription create/update` | `nullable` | `May be null until cancellation is scheduled` |

## 5. Error Contract Rules `[required]`

Example:
- `400` for validation failures
- `401` for missing or invalid token
- `403` for tenant scope violation
- `404` for unknown tenant-scoped resource
- `409` for state transition conflicts

## 6. Rate Limiting Rules `[required]`

Example:
- `Write endpoints: 60 requests/minute per tenant`
- `Read endpoints: 300 requests/minute per tenant`

## 7. Breaking vs Non-Breaking Change Rules `[required]`

Example:
- `Adding a required request field is breaking.`
- `Removing an enum value accepted by clients is breaking.`
- `Adding an optional response field is non-breaking unless clients are documented to checksum exact payloads.`

## 8. Prohibited Agent Actions `[required]`

Example:
- `Do not add undocumented response fields.`
- `Do not silently change auth from bearer JWT to API key.`
- `Do not collapse 403 and 404 behavior without approved CCR.`
